# Krish Yadav — Portfolio

A personal portfolio website showcasing my projects, technical skills, and experience in Computer Science and Artificial Intelligence & Machine Learning.

## About

I'm pursuing a B.Tech in Computer Science and Engineering, specialising in AI & ML at UPES, Dehradun.

This portfolio brings together my work in AI/ML, computer vision, medical imaging, and robotics in a cinematic, anime-inspired visual experience.

## Built With

- React
- TypeScript
- Vite
- Tailwind CSS
- GSAP and Lenis for animations and smooth scrolling
- Lucide React for icons

## Features

- Cinematic, painterly landscape backgrounds
- Scroll-driven animations and layered visual transitions
- Responsive layouts for desktop, tablet, and mobile
- Sections for projects, experience, skills, and contact
- Links to project repositories and relevant demos
- Accessibility support, including reduced-motion preferences

## Run Locally

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/krishyadav25/krish-portfolio.git
   ```

2. Open the project directory:

   ```bash
   cd krish-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

### Production Build

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
